## 🏗️ Technical Architecture

### Frontend (React + Vite + Tailwind)
- **Modern Stack**: React 18 with Vite for lightning-fast development
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Component Architecture**: Reusable components for scalability
- **Smart Routing**: Client-side routing with React Router v6

### Backend (Netlify Functions)
- **Serverless**: No server maintenance required
- **AI Integration**: Claude API for intelligent career counseling
- **Security**: Rate limiting, input sanitization, CORS protection
- **Scalable**: Automatically scales with user demand

### Deployment (Netlify)
- **Free Hosting**: Netlify's generous free tier
- **CI/CD**: Automatic deployments from GitHub
- **Global CDN**: Fast loading worldwide
- **HTTPS**: Secure by default

## 🚀 Getting Started (Quick Setup)

### 1. Development
```bash
npm install
npm run dev
# Open http://localhost:5173
```

### 2. Get AI Chat Working
- Sign up for Anthropic API key
- Add to `.env`: `ANTHROPIC_API_KEY=your_key`

### 3. Deploy to Netlify
- Connect GitHub repo to Netlify
- Add API key in Netlify environment variables
- Deploy! 🎉
